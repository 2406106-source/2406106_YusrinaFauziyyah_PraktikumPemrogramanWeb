## 📝 Tentang Repositori

Repositori ini dibuat untuk menyimpan seluruh hasil pengerjaan **Tugas, Modul, dan Proyek** pada mata kuliah **Praktikum Pemrograman Web**. Repositori ini berfungsi sebagai dokumentasi proses belajar dalam mengembangkan aplikasi web dari tingkat dasar hingga lanjut.

### 🎯 Tujuan Pembelajaran:
- Memahami struktur dasar web menggunakan HTML5 & CSS3.
- Menguasai dasar-dasar pemrograman JavaScript interaktif.
- Mengimplementasikan konsep Server-Side Scripting (PHP / Node.js).
- Mengintegrasikan basis data (MySQL) dengan aplikasi web.
- Menerapkan prinsip *Responsive Web Design* & Clean Code.

## 🚀 Cara Menjalankan Project

### 1. Prasyarat System
- Web Browser (Google Chrome, Firefox, atau Edge)
- Web Server Lokal (XAMPP / Laragon / Live Server VS Code)
- Git installed

### 2. Langkah-Langkah

1. **Clone Repositori ini:**
   ```bash
   git clone https://github.com/YusrinaFauziyyah/2406106_YusrinaFauziyyah_PraktikumPemrogramanWeb.git
   ```

2. **Masuk ke Direktori Project:**
   ```bash
   cd 2406106_YusrinaFauziyyah_PraktikumPemrogramanWeb
   ```

3. **Menjalankan File HTML/JS:**
   - Buka direktori modul yang diinginkan.
   - Buka file `index.html` menggunakan browser pilihan Anda atau gunakan ekstensi **Live Server** di VS Code.

4. **Menjalankan File PHP (jika ada):**
   - Pindahkan folder project ke folder `htdocs` (XAMPP) atau `www` (Laragon).
   - Jalankan Apache & MySQL dari control panel.
   - Buka browser dan kunjungi `http://localhost/2406106_YusrinaFauziyyah_PraktikumPemrogramanWeb/`.
