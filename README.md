## ⚙️ Langkah Inisiasi Dokumentasi

Petunjuk praktikum untuk membuat dan mengonfigurasi file dokumentasi repositori ini di Visual Studio Code:

1. **Buka Visual Studio Code.**
2. Klik menu **File > Open Folder** (atau tekan `Ctrl + K` lalu `Ctrl + O`).
3. Buat folder baru di komputer Anda, misalnya `praktikum-web2026` atau `2406106_YusrinaFauziyyah_PraktikumPemrogramanWeb`.
4. Klik **Select Folder** untuk membuka direktori tersebut di Visual Studio Code.
5. Buat file baru bernama `README.md` di folder utama (root) proyek.
6. Salin dan tempel seluruh isi dari dokumen ini ke dalam file `README.md` Anda.
7. Simpan file (`Ctrl + S`) dan lakukan *commit* serta *push* ke GitHub.

## 🚀 Cara Menjalankan Project

### 1. Prasyarat System
- **Web Browser**: Google Chrome / Mozilla Firefox / Microsoft Edge.
- **Code Editor**: Visual Studio Code.
- **Local Web Server**: Laragon (dengan Apache & MySQL berjalan di Port 3306).
- **Environment**: Node.js & Git telah terinstal.

### 2. Menjalankan secara Lokal

1. **Clone Repositori:**
   ```bash
   git clone https://github.com/YusrinaFauziyyah/2406106_YusrinaFauziyyah_PraktikumPemrogramanWeb.git
   ```

2. **Pindahkan Folder ke Direktori Laragon:**
   Pindahkan folder hasil clone ke dalam folder `www` Laragon:
   ```text
   C:\laragon\www\2406106_YusrinaFauziyyah_PraktikumPemrogramanWeb
   ```

3. **Buka di Browser:**
   Akses melalui URL berikut pada browser Anda:
   ```text
   http://localhost/2406106_YusrinaFauziyyah_PraktikumPemrogramanWeb/
   ```

## 🔄 Panduan Workflow Git

Perintah standar Git yang digunakan selama praktikum untuk memperbarui repositori:

```bash
# 1. Cek status perubahan file
git status

# 2. Tambahkan seluruh perubahan file ke staging area
git add .

# 3. Lakukan commit dengan pesan yang jelas
git commit -m "docs: update README.md modul 1 praktikum web"

# 4. Push perubahan ke cabang utama di GitHub
git push origin main
```
